## ✨ Что это

**Dataset Builder** — веб-приложение для быстрой разметки датасетов с полным циклом:

1. **Создай проект** и укажи класс объекта (например, `Pig`, `Car`, `Person`)
2. **Загрузи** фотографии или импортируй готовый датасет (COCO / YOLO / CVAT / Label Studio)
3. **Авторазметка** — YOLOv8 находит объекты, ты только правишь
4. **Обучение** — когда накопилось 50+ размеченных кадров, обучи свою модель прямо из UI
5. **Экспорт** — YOLO или COCO с автоматическим train/val/test split

Всё работает **локально**: данные остаются на твоём компьютере, никаких облаков.

## 🆕 Что нового в V7

### 🎯 Мультиклассовые проекты

Раньше приложение работало только с классом `pig`. Теперь — **любой класс из 601 класса OpenImages V7** или **свой собственный**:

- **Класс проекта** задаётся при создании и меняется в настройках (⚙ на строке проекта)
- **Список классов** берётся из активной YOLO-модели — есть поиск по названию
- **Свой класс** — если обучил на `cow_spotted` и хочешь размечать именно его
- **Защита от потери данных** — сменить класс можно, только если в проекте ещё нет рамок

### 🗑 Корзина проектов

Удалённые проекты не исчезают сразу — попадают в **корзину** с возможностью восстановления:

- Мягкое удаление с автоочисткой через N дней
- Объединённая корзина: и проекты, и изображения в одном списке
- Восстановление одной кнопкой (с уникальными именами при конфликте)

### 📦 Расширенные форматы

Помимо JPEG/PNG/BMP/WebP/TIFF теперь поддерживаются **AVIF**, **HEIC**, **HEIF**, **GIF**.

### 🎨 Прочие улучшения V6 → V7

- **Безопасность**: magic-bytes проверка, safe zip extraction (symlink, absolute path, ratio-bomb), rate limiter, sanitize логов
- **Производительность**: numpy-DCT для pHash (×20 на импорте), sweep-line в валидаторе, batch-commit авторазметки
- **UX**: drag-n-drop файлов, прогресс импорта через polling, скачивание бэкапа одной кнопкой, кастомный color-picker с пресетами
- **A11y**: skip-link, ARIA-атрибуты, focus-trap, focus-return, `prefers-reduced-motion`
- **Дизайн**: мягкое нажатие кнопок, hover-lift на всех интерактивах, статус-плашка sticky, клик по всей строке изображения
- **DEBUG-режим** через `.env` — авто-перезагрузка при правке `.py`

## 🎬 Возможности

### 🖼 Разметка
- **Авторазметка** YOLOv8 (только те классы, что реально знает модель)
- **Ручное рисование** рамок мышью или пальцем (планшет)
- **Перемещение** рамки — протяжка за линию/край
- **Ресайз** — 8 хендлов по углам и сторонам
- **Мультивыбор** рамок (`Shift+клик`), групповое перемещение и удаление
- **Заморозка** рамок — защита от перезаписи при повторной авторазметке

- **Zoom/Pan** — колесо мыши, pinch-zoom, панорама двумя пальцами

### 📦 Импорт / Экспорт
- **Импорт целиком**: zip с картинками + разметкой (автодетект формата)
- **4 формата**: COCO JSON, YOLO TXT, CVAT XML, Label Studio JSON
- **pHash-дедупликация** — одинаковые фото отсеиваются автоматически
- **Прогресс импорта** через polling с фазой и текущим/всего
- **Экспорт** YOLO / COCO с разбиением train / val / test (70/20/10, 80/20, 85/10/5)

### 🤖 Обучение
- **Fine-tune** любой YOLOv8 (nano / small / medium) прямо из UI
- **Live-прогресс** через Server-Sent Events
- **Автоактивация** новой модели после обучения
- **Выбор предобучения**: OpenImages V7 (601 класс) или COCO

### 🎨 Организация
- **Мультиклассовые проекты** — свой объект у каждого проекта
- **Теги** — цветные метки для группировки фото
- **Корзина** — единая для проектов и изображений, с автоочисткой
- **Фильтры** — по статусу (не размеченные, low-conf, сложные)
- **Поиск** по имени, **сортировка** по имени / типу / уверенности

### 🛠 Инструменты
- **Валидатор разметки** — мелкие, вложенные, наложение, вне холста
- **Статистика проекта** — распределение по уверенности, топ сомнительных
- **Похожие кадры** — pHash + копирование разметки
- **CSV-экспорт** статистики
- **Бэкап проекта** — полная копия в zip (фото + разметка + теги)
- **История статусов** — встроенный лог событий

## 🚀 Быстрый старт

### Требования

- **Python 3.10+**
- **MySQL 8.0+**
- ОС: Windows / macOS / Linux

### 1. Клонировать

```bash
git clone https://github.com/Xulkvan/PigDatasetBuilder.git
cd PigDatasetBuilder
```

### 2. Создать базу данных MySQL

```sql
CREATE DATABASE pig_dataset CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. Виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Запустить

```bash
python run.py
```

Открыть в браузере: **http://localhost:8000**

При первом запуске автоматически скачается `yolov8n-oiv7.pt` (6 МБ) — базовая модель для авторазметки.

## ⚙️ Настройка через `.env`

Создай файл `.env` в корне проекта (шаблон — `.env.example`):

```env
# --- MySQL ---
DB_USER=root
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=3306
DB_NAME=pig_dataset

# --- Сервер ---
HOST=127.0.0.1
PORT=8000
DEBUG=0
```

**`DEBUG=1`** → `uvicorn` запускается с авто-перезагрузкой при правке `.py`. HTML/CSS/JS перезагружаются обычным F5.

## 🧠 Как это работает

### Мультиклассовые проекты

**Класс проекта** хранится в `projects.object_class`. При старте авторазметки Dataset Builder сопоставляет его с `model.names`:

- Если класс есть в модели → фильтрует детекции по этому классу
- Если класса нет → возвращает `422` и подсказку «выбери другую модель или обучи свою»
- **«Своё»** (`object_class_source='custom'`) — если пользователь обучал модель на своём классе

Класс меняется в **настройках проекта** (⚙ на строке). Но только если **в проекте нет ни одной рамки** — иначе кнопка блокируется, чтобы случайно не потерять разметку. Есть кнопка **«Очистить всю разметку»** для разблокировки.

### Авторазметка
YOLOv8 обрабатывает кадр, оставляет детекции целевого класса, дедуплицирует по IoU > 0.5 и сохраняет. Замороженные вручную рамки **не перезаписываются**.

### pHash-дедупликация
DCT-хеш 64 бита через **numpy** (в 20 раз быстрее чистого Python). Поиск дубликатов по бакетам (первые 4 hex) + SWR-кэш. Порог Hamming ≤ 6.

### Обучение
1. Размеченные изображения копируются в `runs/train_<ts>/dataset/`
2. Split **85% train / 15% val** (детерминированно, seed=42)
3. `yolo detect train` с `freeze=8`, `lr0=0.001`, `cos_lr=True`
4. Прогресс стримится в UI через SSE
5. По завершении `best.pt` копируется в `models/` и активируется

### Бэкап
Один zip содержит `meta.json`, `images_index.json`, `annotations.json`, `tags.json` и все фото. Скачивается одной кнопкой сразу после создания.

## ❓ FAQ

**Где хранятся фото и разметка?**
Фото — в `uploads/`, метаданные и разметка — в MySQL (`pig_dataset`). Модели — в `models/`. Всё локально, ничего не уходит в облако.

**Что делать если нет видеокарты?**
Всё работает на CPU. Обучение будет медленнее, но авторазметка и разметка — быстро.

**Как перенести проект на другой компьютер?**
Настройки → Сделать бэкап → кнопка «Скачать». На новом компьютере — «Импорт» через UI.

**Сколько фото нужно для хорошего обучения?**
Минимум 30–50 размеченных. Для стабильного результата — 200+.

**Как размечать не свиней, а что-то другое?**
Создай проект → в поле «Класс объекта» начни печатать. Например, `Car`. Если класса нет в списке OIV7 — обучи свою модель на этом классе и введи его как «своё».

**Работает на телефоне / планшете?**
Да, с поддержкой тача (pinch-zoom, панорама двумя пальцами, крупные хендлы).
