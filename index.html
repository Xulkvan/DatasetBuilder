Загрузка…

Модель обучается на текущей разметке выбранного проекта. Активная модель используется для авторазметки.

Авторазметка

«Добавлять» — старые рамки сохраняются, дорисовываются только новые. «Заменять» — старая разметка (кроме замороженных) стирается.

Точнее, но ~2× медленнее. Полезно на сложных кадрах.

Отладка

Когда включено — авторазметка покажет все объекты, которые видит модель, серыми пунктирными рамками с подписью класса. Сохранятся только объекты целевого класса проекта.

Обучение модели

Ожидание

Форма обучения YOLO-модели на текущем проекте. Заполни параметры и нажми «Запустить обучение».

Обучаемся на размеченных изображениях текущего проекта (неразмеченные в датасет не идут). Для 20–100 фото оставь freeze=8 и lr=0.001. Имя модели можно не задавать — тогда будет train_<дата_время>.pt.
