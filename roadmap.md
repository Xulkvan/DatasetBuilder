🟡 M2 — Скелет (keypoints)

Цель: задача 2\* из схемы.



2.1. Схема keypoints для КРС



Смотрю на рисунок скелета коровы у начальника. Стандартная схема — 17–20 точек:



\#	Точка	Описание

1	nose	нос

2	head\_top	макушка

3	neck	шея

4	withers	холка (верх спины)

5	mid\_spine	середина спины

6	hip	таз

7	tail\_base	основание хвоста

8-11	front\_left (4 точки)	плечо → локоть → пясть → копыто

12-15	front\_right	то же справа

16-19	rear\_left	бедро → колено → скакательный → копыто

20-23	rear\_right	то же справа

Всего \~19–23 точки. Нужно согласовать с начальником точную схему — на его рисунке видны только холка, колено, копыто.

🟠 M3 — Трекинг

Цель: задача Доп. №1\* (трекинг + маршрут + расстояние).



3.1. Автотрекинг между кадрами



ByteTrack / BoT-SORT — из ultralytics, работает на CPU



Кнопка \[Авто-трекинг по видео] — обрабатывает последовательность кадров



Результат: каждому bbox присваивается track\_id, он же пишется в animal\_id



3.2. Ручной режим связки



Кнопка \[Связать с предыдущим] — копирует animal\_id из кадра N-1 в текущий



Умный матч: если bbox перекрывается с bbox предыдущего кадра > 50% — предложить тот же ID



3.3. Маршрут + расстояние



Хранить centroid\_x, centroid\_y (нормализованные) для каждой рамки



По треку строится полилиния маршрута



Расстояние: sqrt((x₂-x₁)² + (y₂-y₁)²) × K где K — калибровочный коэффициент



Вектор движения: (dx, dy) между последовательными кадрами



3.4. UI: оверлей трека



Линия маршрута поверх холста



Стрелка вектора движения



Список треков в сайдбаре: #42 — 15 кадров, маршрут 3.2 м



Работы: 4–6 дней.



⚠️ Проблема: без калибровки камеры метры не посчитать точно. Нужен эталон (известный размер объекта) или уточнение у начальника.



🔴 M4 — Классификация поведения по скелету

Цель: задача 2\* — автоматически определять поведение.



4.1. Правила на основе углов



Лежит: угол «холка — таз — колено» < 30°



Стоит: угол > 150°



Ест: голова ниже линии холки



Пьёт: голова ниже + смещение вперёд



Ходит: изменение координат лап между кадрами > порога



4.2. Обучаемый классификатор (опционально)
